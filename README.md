# KC LMS

KC LMS is an Android application project for private media browsing
and secure peer-to-peer access between Android devices.

## Current stage
- Initial Android application structure
- Basic home screen
- GitHub Actions debug APK build

## Planned features
- Device media browser and folder creation
- Per-folder and per-file password protection
- Master password and secure password manager
- Secure peer-to-peer device connection
- Live media viewing and on-demand downloads

Security and peer-to-peer features are planned and are not implemented yet.

## Build
GitHub Actions builds a debug APK when code is pushed to `main`.
Open the repository's Actions tab and download the
`KC-LMS-debug-APK` artifact after a successful run.
